#Lab 2: Plagiarism Detector

# Project overview

The Plagiarism Detector project is a Python application to compare two essays (essay1.txt and essay2.txt) to identify the similarity in the content based on the Jaccard Similarity.
It works with text, provides word search, provides word frequency reports, and indicates a plagiarism rate.

#Setup
If you run the setup script, the necessary folders are automatically created(two essays for testing, a reports folder for similarity reports, and a setup.log for confirming setup).

bash 
./setup.sh 

After running the setup script, you have to type any word in the essay to check if it was plagiarized in the two essays.
